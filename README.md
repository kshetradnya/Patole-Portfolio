# Vivek Patole · Portfolio

Personal site for Vivek Patole, Vice President of Engineering at KEC International: 30+ years of civil and structural engineering in EPC.

A single static page (`index.html`) with no build step. GitHub Pages publishes it on every push to `main`.

## Sections
- **Hero:** name, title and the day-time bridge film
- **About:** bio, education and credentials
- **Track record:** pinned counters
- **Career:** timeline from Chemtex (2005) to KEC International today
- **Projects:** polaroid line carousel of project sectors
- **Skills:** blueprint sheets on a plan rail that turn, open and flip
- **Approach:** governance, value engineering, digitisation
- **Contact:** night-time bridge film and LinkedIn link
